# Task: docs-from-diff

## Goal
Текущая ветка ушла вперёд базовой. Разберись, что именно в ней изменилось, и приведи документацию
в соответствие с этими изменениями: если в проекте появился новый механизм, файл или настройка -
их должно быть видно в документации, которая это описывает.

Границу задаёт список изменившихся файлов: документы, к этим файлам не относящиеся, не трогай,
даже если заметил в них настоящее расхождение. Изменение может касаться не отдельного модуля, а
проекта целиком - тогда его место в общей документации проекта.

Правки вносятся только в документацию, исходный код не трогай. Если изменения документации не
касаются вовсе - так и ответь, перечислив изменившиеся файлы и объяснив, почему.
