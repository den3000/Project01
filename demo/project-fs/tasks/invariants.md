# Task: invariants

## Goal
В `AGENTS.md` перечислены критические инварианты проекта - правила, которые нельзя нарушать.
Проверь каждый из них по фактическому коду и собери отчёт в файл `docs/invariants-report.md`: для
каждого инварианта - подтверждён он или нарушен, и ссылка путь:строка на то место кода, которое это
доказывает. Инварианты, которые невозможно проверить чтением файлов, так и помечай - это
нормальный результат, а не провал.
