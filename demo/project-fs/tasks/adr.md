# Task: adr

## Goal
Решение о локальном хранении задач в проекте нигде не записано - оно существует только в виде кода.
Восстанови его и запиши как ADR в файл `docs/adr-0001-local-persistence.md`.

Границы разбора: каталог `data/local` во всех платформенных наборах исходников модуля shared-ui,
плюс те места, где база собирается и отдаётся приложению через DI. За эти границы не выходи -
остальной код проекта в этой задаче не рассматривается.

Ответь по коду на пять вопросов и на каждый дай ссылку путь:строка:
1. какой механизм хранения выбран и чем он сконфигурирован;
2. что именно различается между платформами, а что общее;
3. как устроена схема данных - сущности, их поля и преобразования типов;
4. какие следствия это решение накладывает на сборку модулей;
5. какие альтернативы код исключает - то есть что сделать уже нельзя, не переписав этот слой.

Заголовки ADR: Контекст, Решение, Последствия, Альтернативы. Пункт, который не удалось подтвердить
вызовом инструмента, помечай «не проверено» - это нормальный результат.
