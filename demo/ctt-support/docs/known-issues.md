# Известные ограничения

Это учебная демо-версия под alpha-форк Compose для Авроры. Часть ограничений — намеренные, часть —
следствие текущего состояния форка.

## Сервер

### PUT-эндпоинта нет — обновление задачи идёт через POST с известным id

Первое, что смущает при работе с API вручную: `PUT /api/tasks/{id}` не реализован. Обновление
задачи выполняется тем же `POST /api/tasks` — если в теле пришёл ненулевой id, сервер удаляет
запись с этим id и вставляет присланную. Полностью заменяет — поля, которые вы не прислали,
исчезнут. См. [tasks.md](tasks.md#редактирование).

### Задачи не переживают перезапуск сервера

`MutableList<Task>` живёт в памяти процесса, без БД. `./gradlew :server:run` начинает с пустого
списка. Это ожидаемо для демо.

## Аврора (форк Compose 0.0.4-aurora)

### Modal Bottom Sheet не работает

Компонент есть в API форка, но в текущей сборке зависает — отсутствует `MainUIDispatcher` в
Skiko-порте. В коде демо BottomSheet заменён на выпадающий список / диалог. В сообществе Aurora
Developers уже есть порт с фиксом; когда он попадёт в официальный форк — код можно вернуть.
Проявляется, среди прочего, в диалоге смены приоритета задачи.

### Аврора собирается отдельным запуском Gradle

Свойство `-PbuildVariant=aurora` глобально переключает Compose-плагин на форк. Android/iOS и
Аврору **нельзя** собрать в одном запуске: они используют разные версии Compose-плагина.
См. [installation.md](installation.md#аврора--rpm).

### Иконки — Android Vector Drawable, а не SVG

Форк рендерит только SVG, поэтому для Авроры XML-vector парсится в `ImageVector` собственным
загрузчиком (`shared-ui/src/linuxMain/.../vectorxml`). Синтаксис `painterResource` на местах вызова
остаётся каноническим — но новые иконки нужно добавлять как Android Vector Drawable, а не как SVG.

## Клиент (все платформы)

### Индикатор «Offline» не буферизует правки

Пока сервер недоступен, локальные изменения не отправляются и не сохраняются в очередь на потом —
их нужно будет повторить, когда индикатор снова станет зелёным. Локальная копия в Room отражает
последний ответ сервера, а не «локальные ещё-не-отправленные правки».

### Нет уведомлений, нет напоминаний по дедлайну

CTT не показывает push-уведомления и не умеет напоминать о задачах: сущность `Task` не содержит
дедлайна.
